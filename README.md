# Prime Number Checker and Performance Analyzer

## 1. Prime Checker Script (`prime_checker.sh`)

### Description
This script prompts the user for a number, checks if it is prime, and logs the result along with the execution time in milliseconds to `results.csv`.

### Features
- Checks if the input number is prime by testing divisibility up to its square root.
- Logs the execution time and result in the format `<number>, <execution_time_in_seconds.milliseconds>`.
